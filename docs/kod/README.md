# 可道云手册语料

本目录是项目维护的手册快照，不代表上游最新文档。历史导入未完整保留来源 URL、产品版本与导入日期；这些信息目前待补核，不能用本次修改日期替代原始采集日期。

- user/：用户操作手册；admin/：管理员手册。帮助工具递归检索这两个目录。
- api.md：网盘设置工具使用的上游接口允许列表及参数说明。
- 本插件自身接口见 [开发接口](../development/api.md)，使用说明见 [用户指南](../user-guide.md)。

更新语料时记录来源 URL、对应可道云版本、采集日期和人工核对范围。保留原有相对路径以避免历史链接失效；新增截图需确认可公开并记录来源。部署时同步整个目录到 DSH 插件相对位置 ../../docs/kod，重启 DSH 刷新缓存。

帮助检索返回小节摘要和指向 GitHub 对应文档的原文链接。摘要可能截断，具体步骤需结合原文及实际版本核对；链接需要可访问 GitHub。修改在线文档站地址时统一更新服务端 helpSourceUrl，并验证嵌套路径与中文文件名。
