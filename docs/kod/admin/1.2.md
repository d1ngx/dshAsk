### 1.2.2 安全设置

可道云从架构设计到部署方案均注重数据安全。以下设置项供管理员按需开启。

- **登录验证码**：开启后，登录时需输入验证码，可有效防止恶意暴力破解。
- **密码强度**：可选择普通、中等、高强度等密码规则，避免弱口令。
- **密码锁定**：连续 5 次输错密码后，账号将被临时锁定。
- **CSRF 保护**：CSRF（跨站请求伪造）是指攻击者冒充已登录用户发起恶意请求。开启后可降低此类攻击风险。

> **说 明**
>
> 开启 CSRF 保护后，若出现「token_error」错误，通常表示服务器安全配置不完整。可暂时关闭 CSRF 保护继续使用，但请注意安全风险。

- **根目录访问**：开启后，管理员可在地址栏输入服务器物理路径（如 C:/）访问其他目录；关闭后仅可访问可道云安装目录。建议基于安全需求审慎开启。

- **文件存储加密**：对上传文件进行加密存储（隐藏真实文件名和后缀），降低恶意程序被直接执行的风险，并有效防范勒索病毒。

> - **全部加密**（推荐）：即使拥有服务器权限也无法获知文件真实内容。
> - **保留扩展名**：文件名加密，保留文件扩展名。
> - **不加密**：保留原始文件名（安全性较低）。

可道云默认采用「全部加密」方式，强烈推荐保持此设置。

### 1.2.3 用户注册与快捷登录

- **第三方登录**：可道云集成了微信、QQ、Github 等第三方登录方式，管理员可勾选允许用户使用的快捷登录方式。
- **开启用户注册**：开启后，用户可在登录页通过快捷登录、邮箱注册、手机注册等方式自助注册。
- **开启注册审核**：开启后，自助注册的用户需经管理员审核通过后才能正常登录。
- **注册用户默认设置**：可设置自助注册用户的默认空间大小、权限角色、归属部门及对应权限。

### 1.2.4 上传下载设置与优化

- **上传速度优化**：可设置上传分片大小、并发线程数等参数来优化上传速度。
- **上传设置**：可设置上传失败自动重传次数、上传忽略文件类型等。
- **下载限速**：限制下载速度，适用于并发访问量较大的场景。
- **外链分享打包下载**：外链分享文件夹时支持打包压缩下载，高并发时会占用较多服务器性能。

>**提示**
>
> 上传下载优化针对自行部署的环境。如需进一步调优，请参考 [**配置优化文档**](http://doc.kodcloud.com/#/others/options)

### 1.2.5 邮箱设置

邮箱服务器用于用户注册验证、密码找回、系统通知等场景。

- 系统默认使用可道云官方邮件服务器发送邮件
- 管理员也可自行配置邮件服务器，使用自定义邮件服务发送系统通知

### 1.2.6 网站备案号/其他设置

在 **「系统设置」→「基础设置」→「其他设置」** 中，可自定义网站备案号等信息。

- **清空缓存**：点击后会清除系统临时目录（如 `data/temp`）中的缓存文件。

> 说 明
>
> 执行该操作后，AutoCAD 等格式的预览缓存也会被清除，可能影响后续预览速度。

- **自定义全局 CSS**：管理员可通过自定义 CSS 实现多种界面调整，例如：
  - 去除桌面随机壁纸
  - 多语言只保留中文
  - 自定义用户桌面文件夹目录
  - 配置静态文件 CDN 访问 URL
  - 配置插件静态文件到 CDN
  - ...

> **说 明**
>
> 更多自定义需求可参考 [**API 文档**](https://doc.kodcloud.com)

- **统计代码**：为网站添加第三方访问统计代码
