## 1.4.1 添加菜单

进入 **后台管理 → 系统设置 → 菜单管理 → 新增**，即可创建自定义菜单。

各字段说明：

- **使用权限**：指定哪些用户或部门可以看到并使用该菜单
- **菜单名**：菜单上显示的文字
- **URL地址**：点击菜单后打开的页面地址
- **图标**：菜单左侧显示的图标
- **打开方式**
  - **当前页**：在当前可道云页面内打开，替换当前内容
  - **新窗口**：在浏览器新标签页中打开
  - **嵌入页面**：在当前可道云页面内以 iframe 方式嵌入
  - **对话框**：以弹窗形式打开
- **子菜单**：默认关闭。开启后，该菜单会收起到「更多」分组中
- **是否显示**：默认开启。关闭后菜单不会出现在侧边栏

## 1.4.2 管理插件菜单

部分插件安装并启用后，会自动在侧边栏添加菜单入口。

如需调整显示方式，可在插件配置中隐藏侧边栏菜单，或开启**子菜单**将其收起到「更多」中。
