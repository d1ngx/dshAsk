登录管理后台后，首页「系统预览」提供网盘运行状态的一览视图，帮助管理员快速了解当前使用情况。

### 1.1.1 用户信息概览

可在此查看：

- 用户总数、已禁用用户数
- 今日登录人数
- 当前在线人数

### 1.1.2 总存储文件概览

可在此查看：

- 总存储占用
- 文件总数
- 今日新增文件数

### 1.1.3 文件访问信息概览

可在此查看近期的文件活动，包括上传、下载、编辑、删除等操作记录。

### 1.1.4 系统信息概览

可在此查看系统盘、数据盘使用情况，以及服务器运行环境信息（PHP 版本、数据库类型等）。

### 1.1.5 部门/用户存储使用预览

可按时间或空间维度，查看各部门和用户的存储占用情况，便于进行容量规划。
