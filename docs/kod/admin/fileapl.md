>
> 本节仅适用于单独购买该插件的企业用户。免费用户请忽略本环节。

### 概述

文档审批插件提供两种审批流程：

- **权限审批**：用户申请获取某个文件夹的更高操作权限
- **文档发布**：用户申请将文件归档发布到指定目录

管理员还可以自定义审批流程和审批人规则。

### 使用说明

#### 文档发布

文档发布用于将文件正式归档到指定目录，一般流程如下：

1. 用户对指定文件（夹）右键，选择发起「文档发布」审批，填写：
    - **标题描述**：简要说明发布内容
    - **详情说明**：补充详细信息
    - **发布目录**：文件归档的目标目录
    - **审批人**：对发布目录拥有**拥有者**权限的用户，通常是部门管理员；如有多个可任选

2. 审批人在「文档审批」页面查看申请详情，决定是否通过

> **提示：**
>
> **部门管理员**指在该部门的文档权限为**拥有者**的用户。

#### 权限申请

权限申请用于获取某个文件夹的更高操作权限，一般流程如下：

1. 用户对权限不足的文件夹右键，选择发起「权限审批」申请，填写：
    - **标题描述**：简要说明申请原因
    - **详情说明**：补充详细信息
    - **审批文档**：需要申请权限的目标文件夹
    - **审批人**：对该文件夹拥有**拥有者**权限的用户，通常是部门管理员
    - **申请权限**：选择希望获得的文档权限，例如当前为「预览者」，申请升级为「编辑者」

2. 审批人在「文档审批」页面查看申请详情，决定是否通过

### 自定义审批流程

管理员可在「文档审批」页面的「应用管理」中新增审批应用，配置项包括：

- **应用名称**：审批流程的名称
- **应用类型**：「文档发布」或「权限申请」
- **发布高级设置**：限定哪些用户、文档或目录可以使用此流程
- **限定可审批文档**：仅指定文档可发起审批
- **限定发布目录**：仅指定目录可作为发布目标
- **限定发布父目录**：仅该目录及其子目录可作为发布目标
- **审批人设置**：自动获取部门**拥有者**、指定**单人**或**多人**审批
