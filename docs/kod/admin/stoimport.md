## 环境要求

无特殊要求。

## 插件介绍

该插件通过扫描磁盘或对象存储中的已有文件，自动建立索引映射，将文件快速导入到网盘中显示和管理，**不会移动或修改原始文件**。

> **注意**
>
> - 导入的文件需通过存储路径访问，因此导入前需先将原始数据目录（或其父目录）添加为存储挂载。
> - 此操作只建立索引，不改动原始数据。导入完成后，**请勿修改或移动原始文件**，否则索引会失效。
> - 导入数据的路径结构与网盘默认存储不同，建议将导入存储设为附加存储（非默认存储），以保持数据结构统一。
> - 导入前建议备份数据库，以防意外。
> - 文件路径超过 256 个字符的文件无法导入，相关日志保存在网盘目录下的「导入失败日志-长度超256字符」文件夹中，导入完成后可自行查看处理。

## 配置说明

按以下步骤操作：

1. **数据导入**插件在网盘 1.54 及之后版本默认已安装。
2. 从后台**存储管理**页，点击右上方**数据导入**进入配置

3. 在存储管理中新增一个本地存储，路径填写为需要导入的磁盘目录。
4. 将**原始数据目录**设为刚添加的本地存储。
5. 将**网盘存储目录**按需设置，如企业网盘或其他部门目录。
6. 点击确定开始导入，等待执行完成。
