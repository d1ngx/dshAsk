### 6.1.1 登录日志

管理员可在 **后台管理 → 登录日志** 查看所有用户的登录记录。支持按时间范围、指定用户筛选，可查看登录时间和 IP 地址，并支持导出。

### 6.1.2 操作日志

管理员可在 **后台管理 → 操作日志** 查看所有用户的操作记录。支持按日期、指定用户、操作类型筛选，可查看操作时间、具体操作以及涉及的文件，同样支持导出。

### 6.1.3 文档水印

可道云支持为文档添加图片或文字动态水印，防止用户通过截屏、拍照等方式泄露文件内容，保护企业知识产权。管理员可在 **「安全管控」→「文档水印」** 进行配置。

水印配置项说明：

- **使用权限**：设置水印的应用范围，可按用户、部门或权限组指定
- **图片设置**：选择图片水印、文字水印，或不加水印
- **图片水印**：设置水印图片及透明度
- **水印样式**：设置文字对齐、间距，以及主标题、副标题的字体、颜色、大小、透明度、旋转角度等
- **自定义变量**：主、副标题可使用变量，如登录时间、用户 ID、账号、昵称、当前时间等

### 6.1.4 登录管控

管理员可在 **后台管理 → 登录管控** 设置登录限制规则，控制用户从哪些设备、哪些 IP 地址登录。

- **指定用户**：规则适用的用户、部门或用户组范围
- **指定设备**：可道云客户端、网页端、App 端
- **IP 限制**：允许或禁止特定 IP 地址登录

示例：设置两条规则——
- 禁止所有人从指定 IP 登录
- 技术部只能使用网页端登录

>**登录限制说明**
>
> 规则按列表顺序依次匹配；若某条规则的用户范围包含当前登录用户，则以该规则的结果为准。
> 建议将范围较广的规则（如整个部门）放在后面，针对个别用户的规则放在前面（可拖拽调整顺序）。

### 6.1.5 分享管控

管理员可在 **后台管理 → 分享管理** 查看和管理所有分享记录，包括：

- 分享的文件内容、分享形式（外链/协作）
- 浏览和下载次数
- 分享者信息

可按时间、用户、分享形式筛选，并支持导出数据。管理员也可直接取消某个分享。
