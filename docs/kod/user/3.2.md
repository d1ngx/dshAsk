## 3.2.1 上传文件（夹）

### 1 上传

- **拖拽上传**：可直接把电脑里的文件或文件夹拖到浏览器中的可道云页面任意位置，即可上传。
- **点击上传**：在工具栏点击「上传 → 选择文件」，从弹出窗口选择文件。

如需上传整个文件夹，点击「上传」下拉菜单中的「文件夹」，选择目标文件夹即可。

- **批量上传**：支持同时选择多个文件，或直接上传整个文件夹。
- **断点续传**：大文件分段上传；网络中断后可从断点继续，多线程加速。
- **秒传**：若网盘中已有相同文件，系统会跳过重复上传，几乎瞬间完成。

### 2 离线下载

点击「上传」下拉菜单中的「离线下载」，填入文件的 HTTP 链接（网址），服务器会在后台自动下载到您的网盘。

## 3.2.2 下载

选中目标文件，点击工具栏「下载」，即可保存到本地。

- 也可右键文件，选择「下载」。
- 支持将多个文件或整个文件夹自动打包为 ZIP 下载。
