## 2.3.1 搜索

搜索框位于「文件管理」界面右上角。点击搜索框旁的下拉菜单，可以设置搜索条件，帮助您更快、更准确地找到文件。

搜索框具备以下特性：

- **全文检索**：支持在文本文档内容中搜索关键词
- **拼音搜索**：支持输入拼音来查找文件
- **首字母搜索**：支持输入文件夹名称的拼音首字母来查找文件

- **搜索范围**：可限定在当前文件夹内搜索，或在全部文件夹中搜索
- **文件类型**：系统提供了文件夹、文档、图片、音乐、视频等类型；您也可以自定义一种或多种文档格式，进行精确搜索
- **时间范围**：支持按文件创建时间范围搜索
- **文件大小**：支持按文件大小搜索
- **创建者**：在部门网盘中，支持搜索某位创建者的文件

## 2.3.2 文件视图

在文件管理模块中，可道云支持三种查看方式：列表模式、图标模式和分栏模式。

### 1 图标模式

图标模式下，各类文件会以图标形式展示。图片会自动显示缩略图，您可以方便地缩放图标大小，并对文件进行排序。

### 2 列表模式

列表模式下，文件信息排列更整齐，便于管理。列表模式支持自定义调整标题栏宽度、拖动列宽；含有子目录的文件夹可以无限层级展开。

### 3 分栏模式

分栏模式借鉴了 macOS 的操作方式，您可以将多层级文件夹以分栏形式逐层展开，并在各分栏之间拖拽文件，方便管理深层目录结构。

## 2.3.3 信息（属性）面板

选中文件后，可在属性面板中查看以下信息：

- **属性**：显示文件的基本信息，包括大小、文件数、创建者/修改者、个人备注以及标签
- **文档权限**：显示您对此文档拥有的权限
- **文件动态**：记录文件的上传、修改、下载等操作
- **历史版本**：记录文件的所有修改历史，包括修改人、修改时间和修改后的版本
- **关联信息**：显示该文件是否关联了其他文件
