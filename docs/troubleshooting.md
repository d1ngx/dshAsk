# 故障排查

最后核对：2026-10-03。优先在可道云中确认登录、空间与文件状态，再处理 DSH。

| 现象 | 用户可先做什么 | 维护者检查与成功标准 |
|---|---|---|
| 选择空间后仍提示“选择工作区”、不能发送或保存 | 更新后刷新问答页，再选个人/企业空间 | workspace/follow 只能有一次 baseline，后续为 upsert；新会话事件需含 agentAvailable=true 和毫秒时间戳 |
| 选择企业网盘提示凭证过期 | 刷新问答页后重新选择空间 | PHP 与 DSH 都包含 spaceBinding 修复；/kodbox/enter 成功且 catalog.scope 指向企业网盘 |
| 旧对话提示凭证过期 | 从目标网盘目录重新打开问答 | askToken 有效期为 4 小时；不要借用其他对话 token |
| 保存位置不符合预期 | 检查“保存到”；从正确子目录重新进入 | 空间选择器从空间根目录创建对话；文件右键入口保留当前目录 |
| 点击卡片没有预览 | 查看错误说明，登录后重试，或到网盘打开文件 | 核对产物记录、文件权限与 OfficeViewer；权限错误不能通过放开接口解决 |
| OfficeViewer 脚本 404 | 刷新后重试 | /plugins/ 应指向 KodBox，只有 /dsh/plugins/ 指向 DSH |
| 控制台出现 _$ is not a function | 使用“新页面预览”临时查看 | 应用集成目录下 officeviewer-iframe.patch，更新后验证 iframe 预览 |
| 403、页面持续重连 | 重新登录网盘并进入问答 | 检查同源 cookie、受信任 Host、web profile 补丁与服务健康 |
| 同名文件预览错误 | 在网盘确认完整目录 | 检查会话与相对路径，不应只用文件名匹配 |
| 帮助回答找不到依据 | 换成具体操作名称并查看原文 | 检查 docs/kod 同步；更新后重启 DSH 刷新帮助缓存 |

提交问题时附上：操作步骤、发生时间、网盘与 DSH 版本、错误文字。截图应遮住个人资料、私有文件名和链接中的凭证。不要粘贴 cookie、askToken 或模型密钥。
